# Support Ticket Classification System

## Future Interns - Machine Learning Internship
**Task 2: Support Ticket Classification**

## Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning
to classify customer support tickets into support categories.

## Objectives
- Explore and clean customer support ticket data.
- Combine ticket subjects and message bodies.
- Convert text into numerical features using TF-IDF.
- Train a Logistic Regression classifier.
- Evaluate the classification model.
- Visualize ticket categories and priorities.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Workflow
1. Load the dataset.
2. Inspect the columns and missing values.
3. Clean ticket text and remove duplicates.
4. Prepare the target category.
5. Split the data into training and testing sets.
6. Build a TF-IDF and Logistic Regression pipeline.
7. Evaluate the model using accuracy, precision, recall, and F1-score.
8. Test predictions on new ticket messages.
